# Dataset Directory

Place your raw or augmented side-scan sonar image dataset here.

### Subdirectories / Suggestions:
- `data/dataset/train/` (optional, if training)
- `data/dataset/val/` (optional, if evaluating)
- `data/dataset/test/` (sample test images)
- `data/dataset/raw/` (unprocessed sonar images)

### Supported Formats:
- `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tif`, `.tiff`
